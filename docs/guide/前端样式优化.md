## 🔴 P0 — 最优先

### ① App.vue 全量数据预加载

**问题：** 一打开首页就把文章、图鉴、媒体库...十几个 API 全拉了。

**具体做法：**

**第一步：** 把 `App.vue` 的 `onMounted` 里只留**首页真正需要的数据**。

当前 App.vue 的 `onMounted` 长这样：

```typescript
onMounted(async () => {
  await Promise.all([
    postCategoryStore.getPostCategories(),
    postTagStore.getPostTags(),
    postStore.getAllPosts(),         // ← 首页需要（精选、最新文章）
    postStore.getArchives(),          // ← 首页不需要
    dexStore.getDexEntries(),         // ← 首页不需要
    dexStore.getDexStats(),           // ← 首页不需要
    dexGenreStore.getDexGenres(),     // ← 首页不需要
    postStore.getTotalPostsCount(),   // ← 首页不需要
    postStore.getTotalWords(),        // ← 首页不需要
    postStore.getTotalViews(),        // ← 首页不需要
    mediaStore.getMedias(),           // ← 首页不需要
    mediaTagStore.getMediaTags(),     // ← 首页不需要
  ])
})
```

改成只保留首页需要的：

```typescript
onMounted(async () => {
  await Promise.all([
    postCategoryStore.getPostCategories(),
    postTagStore.getPostTags(),
    postStore.getAllPosts(),
  ])
})
```

**第二步：** 在 `Dex.vue` 的 `onMounted` 里加上它自己的数据请求：

```typescript
// Dex.vue 的 script setup 里
onMounted(async () => {
  await Promise.all([
    dexStore.getDexEntries(),
    dexStore.getDexStats(),
    dexGenreStore.getDexGenres(),
  ])
})
```

**第三步：** 同样的方式处理 `Admin.vue`——进入 /admin 页面时再拉 mediaStore、mediaTagStore 等数据，不在全局拉。

## 🎨 一、全局样式问题

### 1. `* { font-family: 'FusionPixelCN', cursive; }` —— 字体覆盖太霸道

所有元素强制使用像素字体，但像素字体不适合长文阅读（文章正文、标签描述等），而且 `cursive` 作为 fallback 和像素字体风格完全不搭（应该用 `monospace`）。

```css
/* 建议分层设计 */
* {
  font-family: 'FusionPixelCN', monospace;  /* 修正 fallback */
}
body {
  font-family: 'FusionPixelCN', monospace;
}
/* 文章正文改用可读性更好的字体 */
.article-content {
  font-family: system-ui, -apple-system, sans-serif;
}
```

### 2. `image-rendering: pixelated` 全局应用

```css
* { image-rendering: pixelated; image-rendering: crisp-edges; }
```

这让**所有图片**（包括文章封面、图鉴封面等用户上传的真实照片）都变成像素渲染。目前你在 `PostCard`、`DexCard`、`DexDetail` 里又手动加了 `style="image-rendering: auto;"` 来覆盖——意味着这是一个已知问题，但用打补丁的方式处理了。

**建议：** 改成只在需要像素效果的容器上应用，而不是全局。

### 3. 缺少 CSS 设计变量 / Design Tokens

像素风的关键数值（`4px` 边框、`box-shadow` 位移、`#2C2C2C` 黑）散落在各组件中重复书写：

- `border: 4px solid #000;`
- `box-shadow: 4px 4px 0px 0px rgba(0,0,0,0.8)`
- `#2C2C2C` / `#000` 混用

有些是 Tailwind 类名（`border-4 border-black`），有些是内联样式，有些是 scoped CSS。不一致会难以维护。

### 4. `body` 背景动画无限播放

```css
body {
  animation: pixelate 5s linear infinite;
}
```

即使页面切到其他路由，这个背景动画仍在运行，持续触发重绘。

**建议：** 只在有背景的区域应用动画，且考虑用 `will-change` + `transform` 优化。

## 🧩 二、组件样式问题

### 5. DexCard 双版本并存（严重）

`DexCard.vue`（蓝光 3D 盒版，已在使用）和 `DexCardPixel.vue`（旧像素卡版，已不再引用）同时存在。

**问题：**
- `DexCardPixel.vue` 开头有 `<!-- @ts-nocheck -->`，TypeScript 完全跳过
- 代码未删除，容易混淆
- 3D 盒版本使用了复杂的 `transform-style: preserve-3d` / `rotateY`，在某些浏览器（尤其移动端 Safari）上可能有问题

### 6. `line-clamp-2` 在三个组件中重复定义

`DexCard.vue`、`Sidebar.vue`、`DexCardPixel.vue` 各自写了同一段 CSS。应该提取到全局样式或 Tailwind 的 `line-clamp-2` 工具类。

### 7. PixelButton 的内联 font-family 冲突

```css
.pixel-btn {
  font-family: 'Press Start 2P', 'Courier New', monospace;
}
```

和全局 `FusionPixelCN` 冲突了。按钮文字用哪套字体？

### 8. `.pixel-card` 中的 background-image 额外网格叠加

```css
.pixel-card {
  background-image: linear-gradient(...);
  background-size: 4px 4px;
  ...
}
```

这给每个像素卡片额外增加了 4px 网格纹理。加上 `::before` 高光层和 `::after` 边框层，**每个卡片有 3 层伪元素叠加**。在大批量渲染图鉴列表时可能影响性能。

## 🏗 三、架构与代码组织

### 9. App.vue 一次性加载所有数据（严重）

```typescript
onMounted(async () => {
  await Promise.all([
    postStore.getAllPosts(),
    postStore.getArchives(),
    dexStore.getDexEntries(),
    dexStore.getDexStats(),
    dexGenreStore.getDexGenres(),
    mediaStore.getMedias(),
    mediaTagStore.getMediaTags(),
    ...  // 十几个请求
  ])
})
```

**问题：**
- 打开首页就拉了**所有模块的全部数据**（文章、图鉴、媒体库…）
- 用户可能根本不去 /dex 或 /admin，浪费流量和内存
- 数据不会自动清理，Pinia store 全局持有到页面关闭

**建议：** 用页面级数据获取，或者至少路由级别的 `beforeEnter` guard。

### 10. Header 的移动端菜单按钮无功能

```html
<button class="md:hidden">☰</button>
```

点了没反应。要配合侧边菜单或下拉面板。

### 11. Admin 页面庞大难以维护

`Admin.vue` 里：
- 7 个 tab 的手动 switch-case
- 表头、表体、操作按钮、删除处理全部手写
- 硬编码分页（`上一页 1 2 3 下一页` 静态按钮）

维护成本高，建议抽成可复用的 `CrudTable` 组件 + 配置驱动。

### 12. 硬编码的假数据残留

Sidebar 里：
```html
<h3>王</h3>
<p>中国</p>
<p>范德萨龙卷风昆德拉数据反馈力度撒娇快乐</p>
```

这显然是 placeholder 还没替换。

## ⚡ 四、性能优化点

### 13. 云朵动画用 `left` 属性

```css
@keyframes cloud-drift-1 {
  0% { left: -150px; }
  100% { left: calc(100% + 150px); }
}
```

`left` 触发 layout 重排。改成 `transform: translateX()` 可启用 GPU 合成。

### 14. 字体文件未预加载

两个 woff2 像素字体（ArkPixelCN + FusionPixelCN）在 `style.css` 里用 `@font-face` 定义但没有 `preload`，加载时会有 FOIT（Flash of Invisible Text）。

### 15. 不必要的 console.log

```typescript
watch(readingProgress, (newValue, oldValue) => {
  console.log(`阅读进度从 ${oldValue}% 变为 ${newValue}%`)
})
```

生产构建时应该移除。

### 16. BGM 文件体积

`未白镇.mp3` 每次加载。建议使用更小的音频格式（如 `.ogg` / `.aac`）或按需加载。
