## 📁 主流 Python 项目结构

### 方式一：脚本放项目根目录（最常用）

```
server/
├── app/
│   ├── main.py
│   ├── models/
│   ├── routers/
│   ├── schemas/
│   └── crud/
├── tools/                          ← 脚本放这里
│   ├── export_all.py
│   ├── import_all.py
│   └── seed_data.py
├── run.py                          ← 启动入口
├── pyproject.toml / setup.py       ← 项目元数据（关键！）
└── requirements.txt
```

**关键不是路径，是你缺了一个 `pyproject.toml`。** 看：

### 🔑 有了 pyproject.toml，问题自动消失

在 `server/` 下建 `pyproject.toml`：

```toml
[project]
name = "adoruworld-server"
version = "1.0.0"

[build-system]
requires = ["setuptools"]
build-backend = "setuptools.build_meta"

[tool.setuptools.packages.find]
include = ["app*"]   # ← 告诉 Python：app/ 是一个包
```

然后安装你的项目（只需要做一次）：

```bash
cd server
pip install -e .
```

**`-e` 是 editable mode**，代码改了立即可见，不用重复安装。

之后 **任何位置、任何方式运行 `tools/` 下的脚本都不报错**：

```bash
# 在 server/ 目录
python tools/export_all.py         # ✅ 可以
python tools/seed_data.py          # ✅ 可以

# 在 server/tools/ 目录
cd tools && python export_all.py   # ✅ 也可以

# 从外面
cd ~ && python server/tools/export_all.py  # ✅ 也可以
```

原理很简单：`pip install -e .` 把你的 `app/` 包注册到了 Python 的 site-packages 里，import 的时候自然就能找到了。

### 方式二：把脚本做成 CLI 命令（更专业）

这是 FastAPI 官方、Django、Flask 都在用的方式——把工具脚本注册成可以直接敲的命令。

在 `pyproject.toml` 里加：

```toml
[project.scripts]
adoru-export = "tools.export_all:main"
adoru-import = "tools.import_all:main"
adoru-seed   = "tools.seed_data:main"
```

然后：

```bash
adoru-seed              # → 跑 seed
adoru-export my.zip     # → 导数据
adoru-import my.zip     # → 导数据
```

**任何目录、任何位置、不需要记得路径。**

### 最大的变化：models/schemas/crud/routers 按模块合并

当前你一个功能（比如 post）要改 4 个目录的 4 个文件：

```
models/post.py → schemas/post.py → crud/posts.py → routers/posts.py
```

改成模块化后，一个功能全在一个文件夹里：

```
modules/post/
  ├── model.py     ← 原来的 models/post.py
  ├── schema.py    ← 原来的 schemas/post.py
  ├── crud.py      ← 原来的 crud/posts.py
  └── router.py    ← 原来的 routers/posts.py
```

**好处**：
- 加新功能 = 新建一个文件夹，不碰别人的代码
- 删除功能 = 删一个文件夹
- 多人协作不会冲突
- `__init__.py` 不用手动导出几十个类

## 📊 两个优化，优先级很清楚

| 优化项 | 工作量 | 收益 |
|--------|--------|------|
| **加 `pyproject.toml` + `pip install -e .`** | 5分钟 | 所有 import 问题永久消失 |
| **按 module 重构文件结构** | 1小时 | 代码更好找，但你现在项目规模没必要急着做 |

**建议今天先做第一项**——5 分钟搞定，你现在所有的脚本运行问题全部解决。重构的事等你加了多租户、代码变多了再考虑～ 😊
