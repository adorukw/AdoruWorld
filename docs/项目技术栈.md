## 📦 这个项目实际用到的所有技术

### 后端（Python）

```
fastapi      → Web 框架（路由、请求、响应）
uvicorn      → ASGI 服务器（让 FastAPI 跑起来的工具）
sqlalchemy   → ORM（用 Python 对象操作数据库）
aiosqlite    → SQLite 异步驱动
pydantic     → 数据校验（定义请求/响应的格式）
python-multipart → 处理文件上传
pillow       → 图片处理（提取宽高、格式等元数据）
mutagen      → 音频处理（提取时长、比特率等）
```

### 前端（TypeScript / JavaScript）

```
vue 3          → 前端框架（组件化 UI）
vite           → 构建工具（开发服务器 + 打包）
vue-router     → 前端路由（页面跳转）
pinia          → 状态管理（全局数据共享）
tailwindcss    → CSS 框架（快速写样式）
marked         → Markdown 渲染（把文章 markdown 转 HTML）
highlight.js   → 代码高亮
typescript     → 类型系统（给 JS 加类型）
```

### 除此之外但很重要的

```
git            → 版本管理
async/await    → Python + JS 的异步编程
RESTful API    → 前后端通信规范
HTTP 基础      → GET/POST/PUT/DELETE, 状态码
JSON           → 数据交换格式
```

## 🗺️ 推荐学习路线

按**依赖顺序**排列，前面的学会了后面的自然明白：

### 第一阶段：Python 基础（1-2 周）

如果你还不太熟悉 Python，这是起点：

```
Python 基础语法
  ├── 变量、类型、函数
  ├── 类与对象（OOP）
  ├── 装饰器（@ 符号那个，FastAPI 里全是用这个）
  ├── 类型注解（def foo(x: int) -> str:）
  └── async / await（异步编程）
```

> **为什么？** FastAPI 大量使用装饰器、类型注解和异步，如果这三个不懂，看代码会一头雾水。

### 第二阶段：Web 基础（3-5 天）

```
HTTP 基础知识
  ├── URL 结构（路径、查询参数）
  ├── 请求方法（GET / POST / PUT / DELETE）
  ├── 状态码（200 / 201 / 204 / 404 / 500）
  └── JSON 格式
```

> **为什么？** FastAPI 本质上就是帮你处理 HTTP 请求和响应的工具。不懂 HTTP 就不懂它为什么存在。

### 第三阶段：FastAPI（1 周）

学顺序：

```
1. 快速上手：一个 main.py 跑起来
   → 看官方文档的"First Steps"

2. 核心概念逐个来：
   ├── @app.get("/path")  — 路由装饰器
   ├── async def          — 异步函数
   ├── Path / Query 参数  — URL 里的参数怎么取
   ├── Pydantic 模型      — 请求体 request body
   ├── Depends()          — 依赖注入（最难但也最精华）
   └── Response Model     — 控制返回格式
```

> 你们项目里核心的结构是：
> ```
> router → Depends(get_db) → crud 函数 → model 操作数据库 → schema 返回
> ```

### 第四阶段：SQLAlchemy（1 周）

你们项目用的是**异步版 SQLAlchemy**：

```
需学内容：
  ├── Base、Mapped、mapped_column → 定义表
  ├── select() 查询、where 过滤
  ├── relationship → 表关联（m对m、1对多）
  ├── async session → 增删改查
  └── ForeignKey → 外键

需明白的概念：
  ├── ORM 是什么（对象 ←→ 数据库表）
  ├── 为什么不用写 SQL 就能查
  └── lazy="selectin" 是什么
```

### 第五阶段：前端 Vue 3（2 周）

```
1. Vue 3 基础
  ├── template 语法（{{ }}、v-if、v-for）
  ├── ref / reactive（响应式数据）
  ├── computed（计算属性）
  └── props / emits（组件通讯）

2. Composition API（你们项目全用这个）
  ├── <script setup lang="ts">
  ├── defineProps / defineEmits
  └── onMounted / watch

3. Vue Router
  ├── router-link / router.push
  └── 路由守卫（beforeEach）

4. Pinia
  ├── defineStore
  └── actions / state / getters
```

### 第六阶段：TypeScript 基础（3 天）

你们前端全用 TS，只学最基础的就能看懂：

```
  ├── :type 注解（变量、函数参数、返回值）
  ├── interface（定义对象形状）
  ├── type（类型别名）
  └── import / export
```

### 第七阶段：Tailwind CSS（1 天就能上手）

```
── 其实就是用 class 名写样式
── class="p-4 bg-sky text-lg border-4 border-black"
── 不需要学很深，查文档就能用
```

## 👣 给你的具体建议

### 如果只有 3 天时间

1. **先跑官方 FastAPI 教程的前 5 页**（First Steps + Path Parameters + Query Parameters + Request Body） → 2 小时
2. **再看你们项目的 `main.py` → `routers/posts.py` → `crud/posts.py` → `models/post.py` → `schemas/post.py`**，按请求的完整流程读下来 → 3 小时
3. **然后看 Vue 的 `App.vue` → `router/index.ts` → `api/index.ts` → `store/post.ts` → `views/Admin.vue`** 看前端怎么调后端 → 3 小时

这 8 小时走通后，你就能串起「浏览器发请求 → 后端处理 → 数据库查询 → 返回数据 → 前端渲染」这条线了。

### 如果想认真学好（1 个月路线）

```
第 1 周：Python 基础 -> 重点是 async/await + 类型注解
第 2 周：FastAPI 官方教程（https://fastapi.tiangolo.com/zh/tutorial/）
第 3 周：SQLAlchemy 基础 + 你们项目的 models 和 crud
第 4 周：Vue 3 入门 + 你们项目的前端部分
```
